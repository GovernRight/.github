# GovernRight

**Make Governance Work.**

GovernRight is a governance framework and cloud platform that helps boards
oversee Growth, Change and Risk, shifting the focus from activity to outcomes.

Built in Sydney for schools, sporting associations, industry bodies,
professional organisations and not for profits across Australia and New Zealand.
